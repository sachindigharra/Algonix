# Algonix — Project Blueprint

## 1. High-Level Functionality

**Core Purpose**: Algonix is a DSA (Data Structures & Algorithms) progress tracker for competitive programmers.
It lets users log solved problems, track contests, follow structured roadmaps, journal daily learning,
and view analytics across platforms like LeetCode, Codeforces, and CodeChef.

**Target Audience**: Engineering students and job-seekers actively grinding DSA for placements/interviews.

---

## 2. Tech Stack & Architecture

### Frontend
| Layer | Technology |
|---|---|
| Framework | React 19 + Vite |
| Routing | React Router DOM v7 |
| State / Data Fetching | TanStack React Query v5 |
| UI Components | shadcn/ui (Radix primitives) |
| Styling | Tailwind CSS v4 |
| Charts | Recharts |
| Excel Parsing | xlsx (SheetJS) — runs in-browser |
| Animations | Framer Motion |

### Backend (in transition)
| Layer | Technology |
|---|---|
| Current (default) | Supabase (PostgreSQL + Auth + Storage) |
| New (being integrated) | Spring Boot (`http://localhost:8080/api/v1`) |
| Auth Strategy | Supabase Auth **or** Spring Boot JWT via HttpOnly cookie |

### Backend Toggle
```
.env → VITE_USE_SPRING_BACKEND=false   # uses Supabase (default)
.env → VITE_USE_SPRING_BACKEND=true    # uses Spring Boot
```
Restart dev server (`npm run dev`) after changing the flag.

## 4. Completed Features

### Authentication
- **Supabase Auth** — email/password login + signup working end-to-end
- `auth-context.jsx` — global session state via `onAuthStateChange`
- Protected routes — unauthenticated users redirected to `/login`
- Files: `src/lib/auth-context.jsx`, `src/pages/Login.jsx`, `src/pages/Signup.jsx`

### Problem Tracker (`/problems`)
- Full CRUD — add, edit, delete problems
- Fields: title, platform, difficulty, status, tags (topics), pattern, companies, approach,
  time/space complexity, sheet, revision dates, notes, URL
- Multi-filter: difficulty, status, platform, sheet, company, topic (multi-select), pattern (multi-select)
- Inline status toggle (solved ↔ todo) directly from the table
- Files: `src/pages/Problems.jsx`, `src/components/problems/`

### Excel Bulk Import (`/import`)
- Drag-and-drop or file-picker for `.xlsx` / `.xls`
- Each sheet = one company; user assigns company name per sheet
- Parses columns: Title, Difficulty, Link, Topics
- Merges duplicate problems across sheets (combines companies + tags)
- Preview table before importing; batched upsert (100 at a time)
- Toggle-aware: Spring Boot path uses `bulkImportProblems()` from `problemApi.js`
- Files: `src/pages/ImportProblems.jsx`, `src/api/problemApi.js`

### Dashboard (`/`)
- Key stats: total solved, streak, patterns mastered, contests joined
- Revision queue (`TodayFocus`) — due problems via spaced repetition algorithm
- Roadmap progress widget, today's activity, pattern mastery breakdown, platform summary
- Files: `src/pages/Dashboard.jsx`, `src/components/dashboard/`

### Contest Tracker (`/contests`)
- Log upcoming and past contests; toggle participated flag
- Fields: name, platform, start time, duration, rank, problems solved, rating change, notes
- Upcoming and history sections with inline edit/delete
- Files: `src/pages/Contests.jsx`

### Learning Journal (`/learning`)
- Daily learning entries with topic tags
- Spaced repetition: entries surface again 4 days later for revision, then 7 days after marking revised
- Files: `src/pages/Learning.jsx`

### Analytics (`/analytics`)
- Daily progress area chart (last 30 days)
- Weekly bar chart (last 12 weeks)
- Platform distribution, sheet progress (Blind75, NeetCode150, Striver SDE, Grind75)
- Topic analysis with solve rate badges, activity heatmap, difficulty breakdown
- Files: `src/pages/Analytics.jsx`

### Study Roadmap (`/roadmap`)
- Two roadmaps: TUF A-Z Sheet (default) and Generic Pattern Roadmap
- Topic statuses: completed → active → unlocked → locked (prerequisite-based)
- Progress bars per topic, link to practice problems
- Files: `src/pages/Roadmap.jsx`, `src/lib/studyRoadmap.js`

### Portfolio (`/portfolio`)
- Developer profile card with avatar upload (Supabase Storage)
- C-Score metric (Easy×1 + Medium×3 + Hard×5 + Contest×10)
- Connected platform cards: LeetCode (live sync), Codeforces, CodeChef, AtCoder (manual)
- Auto-sync for platforms with public APIs
- Files: `src/pages/Portfolio.jsx`, `src/lib/platformFetcher.js`

### Settings (`/settings`)
- Platform profile management (manual entry for stats)
- Files: `src/pages/Settings.jsx`

### Spring Boot field contract for problems
```
Frontend (snake_case)    →  Spring Boot (camelCase/ENUM)
─────────────────────────────────────────────────────────
platform: "leetcode"     →  platform: "LEETCODE"
difficulty: "medium"     →  difficulty: "MEDIUM"
status: "todo"           →  status: "TODO"
sheet: "blind75"         →  sheet: "BLIND75"
pattern: "Two Pointers"  →  patterns: ["Two Pointers"]    ← single → array
approach: "..."          →  approaches: ["..."]           ← single → array
time_complexity          →  timeComplexity                ← snake → camelCase
space_complexity         →  spaceComplexity
revision_dates           →  revisionDates
```
Transform handled automatically by `toBackend()` / `fromBackend()` in `src/api/problemApi.js`.

## 6. Key Patterns & Conventions

- **Data fetching**: always via `useQuery` + `useMutation` from TanStack React Query
- **Query keys**: `['problems', user?.id]`, `['contests', user?.id]`, etc.
- **User resolution**: each page does `supabase.auth.getUser()` in a `useEffect` — will change to `useAuth()` hook when Spring path is active
- **Toast notifications**: `sonner` library via `toast.success()` / `toast.error()`
- **Styling**: Tailwind utility classes + `cn()` helper from `src/lib/utils.js`
- **Path alias**: `@/` maps to `src/` (configured in `jsconfig.json`)
- **No test suite** currently set up
